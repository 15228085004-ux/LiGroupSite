# Teacher guide

## Open the maintenance system

```text
https://15228085004-ux.github.io/LiGroupSite/#/admin
```

Sign in with the account created in Supabase Authentication.

## Safe editing sequence

1. Choose a section in the left sidebar.
2. Change the fields.
3. Click **Preview**.
4. Check the complete public page.
5. Click **Save draft** if the change is not ready.
6. Click **Publish** when visitors should see it.
7. Write a useful version note and confirm.
8. Open the public page in an incognito window.

The public site does not change when only a draft is saved.

## Common updates

### Add a student

1. Open **Team**.
2. Click **Add member** under Current members.
3. Fill name, role, research focus and profile slug.
4. Upload a square portrait if available.
5. Use comma-separated research interests.
6. Separate biography paragraphs with a blank line.
7. Preview the student profile and publish.

### Change the hero

1. Open **Identity & Hero**.
2. Update either headline line and the introduction.
3. Replace hero images through the image controls.
4. Keep the two-line title contrast: line one solid, line two outlined.
5. Preview desktop and mobile.

### Add a user

1. Create the account in Supabase Authentication.
2. Open **Access**.
3. Set the user to Editor.
4. Only trusted core maintainers should receive Administrator access.

### Add an industry partner

1. Open **Partners & Openings**.
2. Under Industry Partners, click **Add partner**.
3. Upload the company logo.
4. Enter the company name and website.
5. Use the arrow controls to set display order.
6. Preview the homepage and publish.

## Undo a mistake

1. Open **Versions**.
2. Find the last known-good publication.
3. Click **Restore draft**.
4. Review the restored content.
5. Publish only after confirming it is correct.

Restoring a version does not immediately replace the public website.

## Emergency checklist

- Verify the correct publication or news item
- Check names, dates, links and technical details
- Preview the full public page
- Publish with a clear version note
- Confirm the public page in an incognito window

If the backend cannot be reached, do not repeatedly click Publish. Record the
time, action and error message, then contact the student maintainer.
